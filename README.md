## Scope

Public server tooling may include:

- Server administration utilities
- Moderation and staff tooling
- Integration components
- Configuration helpers
- Diagnostics and compatibility utilities
- Public plugin interfaces
- Server-side developer examples

Security-sensitive internal tooling and private operational systems should not be published in this repository.

## Compatibility

Supported server software and Minecraft versions will be documented per tool as implementations are released and tested.

## Security

Public code and documentation must not contain server credentials, remote-console passwords, database credentials, private keys, webhook credentials, bot tokens, private infrastructure addresses, or personal information.

Configuration examples should use placeholders.
